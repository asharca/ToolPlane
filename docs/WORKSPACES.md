# 工作空间流程

> **English**: [WORKSPACES.en.md](./WORKSPACES.en.md)

工作空间是成员、共享资源和运行记录的隔离边界。个人语言、主题、时区、密码与
个人 API Token 不属于某个空间。当前成员是可信协作者，不提供资源级只读角色。

## 入口

- `/app?view=workspaces`：空间列表、创建、进入、退出以及失败清理的恢复入口。
- `/app?view=account`：跨空间的个人设置和 API Token；旧空间内的 tokens 页面跳转到这里。
- `/app/[workspace]/members`：成员列表、邀请和撤销邀请、移除成员、主动退出。
- `/app/[workspace]/settings`：名称、默认模型、所有权转移和删除。
- `/app`：恢复当前浏览器中该账号上次访问且仍可访问的空间，或选择一个可访问的空间。
  没有空间时显示空状态，不再隐式创建。市场安装有多个目标空间时先选择目标。

使用查询参数承载账号级页面，避免新增静态路径占用现有工作空间的 slug。
新空间只要求名称，支持中文，最多 80 个 UTF-16 单元，与 HTML maxlength 一致。
地址包含随机后缀；修改名称不会修改地址。新建后进入 Work 开始引导。

## 成员与邀请

所有者管理空间配置、模型服务商、消息渠道凭据和成员；成员使用与编辑业务资源。
服务端以 `Workspace.ownerId` 为所有权依据，不能只依赖 UI 或 Membership.role。
成员退出不删除共享资源；所有者须先把所有权转给一个有效的现有成员。

所有者可在成员页任免现有非所有者成员为工作区管理员。这会一并授予既有 Agent API/客户端
密钥、A2A/远程 Agent/频道操作者、Pi 包来源、市场发布及工作区通知能力，不改变站点角色。
邀请、踢人、重命名、删除、转让和任免仍仅限所有者。挂起账号不能新获管理员权限，但可撤销；
管理员可以退出。转让仅降级原所有者，保留其他管理员。

邀请按邮箱生成，一次性链接有效期 7 天，不依赖 SMTP，也不声称发送了邮件。
数据库只保存 token 哈希。重新生成、撤销、接受和过期都会使旧链接失效。
凭据在 URL fragment 中，页面读入标签页 sessionStorage 后清除 fragment，避免进入
服务器请求日志；同一标签页的登录/注册可以继续邀请。
所有者先预览邮箱，明确确认现有账号的名称和邮箱后才投递站内通知；注册邮箱尚未验证。
站内接受与 token 链接都绑定此账号。删除账号后，同邮箱新账号不能继承旧邀请。
未注册邮箱只能生成链接；后续注册不自动投递或认领通知，仍可凭原 token 和匹配邮箱加入。
预览后账号发生变化必须重新预览，服务端不会静默升级为站内投递。重邀复用待处理邀请通知并重置为未读，旧 token 失效。
接受在工作区行锁内复核账号状态、收件绑定、邮箱、有效期和工作区状态；token/站内并发只有一次成功。
已接受、撤销或过期通知保留历史，但不再提供可用加入操作。

成员增减、邀请消费、所有权转移及删除启动使用同一空间行锁。
移除成员同时撤销该空间的 toolkit token 和遗留邀请，不撤销对方的全局个人 token。
请求会重新验证成员关系；已连接的终端、工作事件和对话输出流在本进程立即断开，
跨进程撤权通过最多 5 秒一次的权限检查断开。

## 私有站内通知

通知使用 PostgreSQL `Notification` 内容与每账号 `NotificationRecipient` 收件记录，不复用协议通知或审计日志。
站点管理员可向正常状态普通账号发布；工作区所有者和管理员可向本区正常状态所有者/成员发布。
指定邮箱会规范化、去重；任一不存在、挂起或越权目标使整次发送失败。受众为发布时快照，后注册/后加入不补发。
标题 1–120 字符、正文 1–5000 字符，均为纯文本；正文换行统一后校验长度，表单 CRLF 不额外占用字符数。内容、每批 500 条收件记录与不含正文/邮箱的审计在同一事务提交，不引入队列。
收件箱与已读操作始终要求当前正常状态收件账号；打开页面不自动已读，单条/全部已读仅影响本人且保留首次已读时间。
收件箱在工作区内以 `/app/<slug>/notifications` 标签页打开，保留侧栏与其他已打开页签；`unread=1` 筛选未读，`page=N` 分页，每页 20 条。无任何工作区时回退 `/app?view=notifications`，账户级权限不变。工作区侧栏、账户页页头和管理侧栏均链接到本人收件箱。
站点发布入口 `/admin/notifications`，工作区发布入口为本区成员页。表单默认指定收件人，成功显示实际提交的收件人数，不提供通用账号搜索。
铃铛在窗口聚焦、恢复可见、收件箱显式操作及可见期间每 60 秒更新计数；失败保留上次数值并提示不可用。新内容需手动刷新收件箱，不用轮询打断正在填写的草稿。
退出工作区、删除发布者/工作区不会删除已收历史，也不会赋予工作区访问权。使用前应用 `20261008083847_in_app_notifications`，生成客户端并重启；不回填旧邀请。

## 删除与部署

需要输入当前空间名称确认，并显示影响数量。状态依次为 `active` → `deleting` →
删除记录；失败时保留 `delete_failed`，不能重新当作可用空间。清理会停止任务、
进程与容器并删除托管卷，不能承诺撤销或恢复已经删除的数据。连接设备的原有文件
不会由此删除。所有者可从空间列表重试，其他成员仍可退出。

清理并发去重目前在单个管理服务进程内；部署多个独立管理 worker 前需要增加可续期
的数据库清理租约。数据库中的关闭状态在重启后仍阻止控制台和运行进程重新启动。

发布包含 `20260908000000_workspace_lifecycle` 迁移；部署时应用迁移、生成 Prisma
客户端并重启应用。不要在未确认目标数据库的情况下执行迁移。
